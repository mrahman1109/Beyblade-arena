# Beyblade-arena

Two small, dependency-free web apps that each run from a single HTML file — just open it in a browser.

## SplitFair (`splitfair/index.html`)

A free alternative to Splitwise for splitting shared expenses with roommates, trips, or couples:

- Create groups and add members
- Log expenses split equally, by exact amounts, or by percentage
- Automatic balance tracking and "who owes whom" simplified into the fewest payments
- Settle up with one click
- Export/import a JSON backup

All data is stored locally in the browser (`localStorage`) — no server, no account, no fees.

## Beyblade Battle Arena (`index.html`)

A physics-based two-player Beyblade battle game played on a canvas arena, with launch power controls, collisions, ring-outs, and an optional bot opponent.
